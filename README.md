# 📅 推しカレンダー

アニメ・ゲーム・VTuber・漫画・音楽など、推しキャラや作品の**誕生日・記念日・発売日・イベント**を管理できるカレンダーアプリです。  
PWA対応により、Androidのホーム画面にインストールしてネイティブアプリのように使えます。

---

## ✨ 機能

| 機能 | 内容 |
|------|------|
| 📅 カレンダービュー | 月ごとにイベントを確認。イベントのある日はカラータグで表示 |
| 📋 一覧ビュー | 直近のイベントを「あと〇日」付きで一覧表示 |
| ➕ イベント登録 | 名前・日付・種別・カテゴリ・グループ・メモを登録 |
| 📂 グループ管理 | 作品・シリーズ・ユニット単位でまとめて管理・絞り込み |
| 🔍 フィルター | カテゴリ／グループ別に絞り込み表示 |
| 💾 データ永続化 | `localStorage` に保存。アプリを閉じてもデータが残る |
| 📲 PWA対応 | Androidホーム画面にインストール可能、オフラインでも動作 |
| 📱 レスポンシブ | PC（2カラム）・スマホ（1カラム）に自動対応 |

### カテゴリ
`✨ アニメ` `🎮 ゲーム` `📖 漫画` `🌟 VTuber` `🎵 音楽` `💫 その他`

### イベント種別
`🎂 誕生日` `🎊 記念日` `📦 発売日` `🎉 イベント`

---


###  Androidにインストール

1. 上記URLをAndroidのChromeで開く
2. 画面下部に表示される **「ホーム画面に追加」** バナーをタップ
3. または Chromeメニュー（⋮）→ **「アプリをインストール」**
4. ホーム画面のアイコンからアプリとして起動できます 🎉

## 📁 ファイル構成

```
oshi-calendar-pwa/
├── index.html        # アプリ本体（HTML + CSS + JS すべて含む）
├── manifest.json     # PWA設定（アプリ名・アイコン・テーマカラーなど）
├── sw.js             # Service Worker（オフラインキャッシュ）
└── icons/
    ├── icon-192.png  # ホーム画面アイコン（192×192）
    └── icon-512.png  # スプラッシュ用アイコン（512×512）
```

> `index.html` 単体に全機能が入っているため、ファイルをブラウザで直接開いて動作確認することもできます。  
> ただし Service Worker（オフライン機能）はHTTPS環境でのみ有効になります。

## 📝 使い方

### イベントを登録する

1. 画面右上の **「＋ 追加」** ボタンをタップ
2. フォームに入力して **「✦ 登録する」** をタップ

| 項目 | 説明 |
|------|------|
| 推し・作品名 | キャラ名・作品タイトルなど（必須） |
| 日付 | 月・日を数字で入力（毎年繰り返し） |
| 種別 | 誕生日 / 記念日 / 発売日 / イベント |
| カテゴリ | アニメ / ゲーム / 漫画 / VTuber / 音楽 / その他 |
| グループ | 作品名・シリーズ名など（任意）。入力済みのものはボタンで選択可 |
| メモ | 自由テキスト（任意） |

### フィルターを使う

- **カテゴリフィルター**：画面上部のボタンでカテゴリ別に絞り込み
- **グループフィルター**：グループ登録済みのイベントをシリーズ単位で絞り込み

### イベントを削除する

- カレンダーの日付をタップ → 詳細モーダルの **「削除」** ボタン
- 一覧ビューの各行にある **「削除」** ボタン

---

## 💡 Tips

- **年をまたぐイベント**も正確に「あと〇日」計算されます
- **グループ名**を統一しておくと、同じ作品のキャラをまとめて確認できます  
  例：`呪術廻戦` グループに五条悟・虎杖悠仁・禪院真希をまとめる
- データは端末の `localStorage` に保存されるため、**ブラウザのデータ削除で消える**点に注意してください
